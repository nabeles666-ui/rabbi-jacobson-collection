# Rabbi Jacobson Collection

54 preserved lectures with individual titles and summaries, audio listening copies, and complete uploaded transcripts.

## Website

https://nabeles666-ui.github.io/rabbi-jacobson-collection/

Static website: publish the main branch root with GitHub Pages.

Editorial titles and summaries are based on automated transcripts. The text is preserved as supplied and may contain recognition errors. Individual speaker attribution follows the source collection and has not been independently verified. Audio listening copies preserve the full duration; original recordings remain unchanged in the source archive.

The homepage photograph was supplied by the collection owner. No license to third-party lecture recordings or photographs is implied by this repository.
